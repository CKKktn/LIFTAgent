# LIFT 合同审查 · V4

使用 LangChain、LangGraph 和 FastAPI 搭建本地合同与技术协议审查系统，支持知识库、带来源的 RAG 问答、快速审查和人机协审。

## 启动

本机已准备好 Python 3.12 环境及依赖。在项目目录双击 **`start.cmd`**，然后打开 [本地系统](http://127.0.0.1:8000/)。首次访问由你自行设置管理员账号和密码；新系统没有沿用原网站的密码。

移到另一台电脑后，需要安装 Python 3.12。启动脚本会建立 `.venv` 并安装 `requirements.lock.txt`，首次安装需要联网。也可以手动运行：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.lock.txt
.\.venv\Scripts\python.exe -m backend.main
```

服务默认仅监听本机 `127.0.0.1:8000`。关闭运行窗口或按 `Ctrl+C` 可停止服务，下次启动会继续使用已保存的资料。

## 模型稍后配置

登录后打开「模型设置」，填入服务商提供的 **API 地址、模型名称、API Key**，保存为默认对话模型，再测试连接。对话接口采用 OpenAI-compatible 的 `/chat/completions` 协议；不绑定某一家服务商。地址应是 API 根路径，例如服务商要求的 `/v1`，不要填写聊天网页地址或重复附加 `/chat/completions`。

暂不配置模型也能管理知识库、上传解析文件和测试本地检索。AI 审查与问答会提示先配置模型，不会用固定文字代替真实模型回答。嵌入模型可独立配置；默认的「本地文本特征」不需要密钥或模型下载，但它不是语义嵌入大模型。更换知识库使用的嵌入模型后，需要重新解析文件。

## 已实现的主要功能

- **知识库**：创建及配置、文件或文件夹上传、后台解析及取消、文件启停、切片查看和编辑、原文件下载、文字及 PDF 预览。
- **快速审查**：后端 LangGraph 提取子图 → 人工中断与修订确认 → 按三类要求条件分支核查 → 有预算的补充检索 → 报告子图；保存 SQLite 检查点，可刷新接回、停止后继续和单独重试异常项。审查依据文件不会作为自身的完成证明。
- **人机协审**：LangGraph 持久工作流串联问题理解、证据检查、有限补检索、草稿生成与校验；重要意见人工确认、修订或退回，支持停止/重启后继续，保留 RAG 来源、历史会话和人工标注。
- **审查记录**：保存、搜索、继续未完成任务、人工修订判定和分析；导出含图表和完整依据的 HTML 报告及原始 JSON 数据。
- **配套工具**：模型接入及连接测试、默认模型选择、检索测试、已实现接口的调试面板。
- **背景样式**：43 款可选样式，包含 7 款 Vanta 立体动态背景和 8 款轻量动态背景；自动保存选择，隐藏页面时暂停，轻量动态支持播放、暂停及跟随系统减少动画设置。Vanta 新增深蓝巨浪、幻彩群鸟、星球连线、星际光晕和光轨星环，支持鼠标互动及帧率自适应。

快速审查保留原界面的**工程技术符合性**范围，主要检查数值指标、功能条件和技术文档交付要求；付款、税费、违约金等商务财务条款不在该自动流程中。

## 工程目录

| 位置 | 内容 |
| --- | --- |
| `backend/` | FastAPI、LangChain 模型与文档接口、LangGraph 快速审查与检索问答、SQLite 检查点 |
| `frontend/` | 已适配本地服务的原有 UI，以及本地 PDF.js 资源 |
| `.local-data/` | 首次启动生成：数据库、上传文件、预览缓存、会话及模型密钥加密所需的秘密文件 |
| `examples/` | 新写的合成资料，可自行上传后体验检索和审查 |
| `tests/` | 后端测试及仅供联调的固定响应模型服务 |
| `tools/import_knowledge.py` | 原件、原站解析文字及本机 OCR 结果的校验迁移；本地建立检索索引 |
| `requirements.lock.txt` | 本次实际安装环境的锁定依赖 |
| `tools/package_app.py` | 构建 V4 源码压缩包 |

## 图纸识别试用

双击 `start-trial.cmd` 启动纯视觉试用版，打开本机 8012 端口。试用目录使用自己的账号、上传文件和模型配置。启动脚本按锁文件安装依赖，PDF 页面由 PDFium 在本机渲染。

1. 在「模型设置」的「模型接入」中选择「视觉 / 图纸识别」，填入实际 API 根地址、模型名和密钥。保存后点击「测试看图连接」，系统会用合成图片核对视觉输入。可设置独立的默认视觉模型，创建知识库时会预选该接入。试用时两版选择同一个视觉模型。
2. 在「知识库配置」选择图纸识别模型。上传 PNG、JPG、JPEG 或带图纸的 PDF，勾选后点「解析」。识别时所选 API 收到图纸页和需要放大的局部。若 PDF 的图纸页未被识别，可在该文件的「⋯」设置中开启全页识别，再解析一次。
3. 点击文件行「图纸证据」查看对照表。点击「打开并核对」回到原图，核对标注、对象和两个定位框，必要时修正后保存。快速审查与人机协审可引用该条记录并跳回原图。

待核对的标注可用于找线索。人工确认后的标注可核验设计图上的指标。成品尺寸与验收结果需要对应实测资料。细字、旋转标注和相邻尺寸线需对照原图。

## 测试

安装 Python 依赖并准备 Node.js 后运行以下命令。前端工作流测试使用 Python 编译当前后端的图结构。

```powershell
.\.venv\Scripts\python.exe -m pytest tests -q
node --test tests/*.mjs
```

Node.js 用于前端状态测试。页面联调使用合成资料和测试服务，真实模型的准确率以带人工核对结果的实际试用为准。Office 预览是文字重排，旧版 Office 格式需安装 LibreOffice。快速审查由后端 LangGraph 执行，关闭网页后后台服务仍可继续。关闭服务后任务暂停，重新启动可手动继续。材料或模型版本变更时需要新建审查任务。当前按单个本地工作空间设计。
